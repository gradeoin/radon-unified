📖 Step-by-Step API Key Setup Guide Zero Cost
1. Google Gemini Key (Get dedicated 15 RPM / 1M token quota)
  1. Visit aistudio.google.com and sign in with your Google account.
  2. Click "Get API Key" in top left → "Create API Key".
  3. Copy your key (starts with AIzaSy...).
  4. Paste it into "Personal Gemini API Key" above & click Save Settings.

⚡ Benefit: Gives you your own dedicated, private free tier quota so you never hit shared traffic rate limits.

2. OpenRouter Key (For DeepSeek R1, V3, Qwen 2.5 & Copilot)
  1. Visit openrouter.ai/keys and sign up for free.
  2. Click "Create Key" and copy your key (starts with sk-or-v1-...).
  3. Paste it into "OpenRouter API Key" above & click Save Settings.

⚡ Benefit: Direct native access to DeepSeek R1 reasoning, Qwen 2.5 Coder 32B, and Microsoft Phi-4 without fallback delays.

3. Multi-Key Rotation in Cloudflare Worker (For Self-Hosters)
  1. Go to Cloudflare Dashboard → Workers & Pages → radon-backend.
  2. Go to Settings → Variables & Secrets.
  3. Edit GEMINI_API_KEY secret and paste multiple keys separated by commas:
    AIzaKey1...,AIzaKey2...,AIzaKey3...
  4. Click Save and Deploy.

⚡ Benefit: Worker automatically round-robins requests across all keys, multiplying total free capacity to 30 RPM, 45 RPM, or 60 RPM!
